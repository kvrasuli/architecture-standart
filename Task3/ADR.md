### **Название задачи: Онлайн-банкинг** 

### **Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case**                                                                                                                                                                                 | **Описание** |
|:-----:|:---------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------|
|   1   | Пользователь интернет-банка      | 1. Пользователь заходит на страницу интернет-банка<br/> 2. Просматривает варианты депозитов со ставками<br/> 3. Оформляет заявку на открытие депозита<br/> 4. Ждет СМС-уведомление о решении |              |
|   2   | Сотрудник бэк-офиса              | 1. Сотрудник просматривает поступившие заявки на открытие депозита<br/>2. Выносит решение по заявке<br/> 3. Инициирует отправку СМС-уведомления                                              |              |

### **Нефункциональные требования**

| **№** | **Требование**                                                     |
|:-----:|:-------------------------------------------------------------------|
|   1   | Должно быть внедрено шифрование трафика                            |
|   2   | Должно быть внедрено масштабирование                               |
|   3   | Время отклика интернет-банка для пользователя должно быть < 100 мс |
|   4   | Поддержание работы системы с SLA 99.9%                             |

### **Решение**
Диаграммы приведены в папке с ADR. Основная часть системы (АБС) монолитная, плохо масштабируется,
Систему интернет банкинга выносим в отдельный МС, это будет первым шагом к новой архитектуре.
Новый МС будет соединен с АБС через шину сообщений.

### **Альтернативы**
Не использовать Kafka на первом этапе, оставить взаимодействие между системами как есть, через менеджеров и почту

**Недостатки, ограничения, риски**
- команда не имеет компетенций для работы Kafka, уйдет доп. время на погружение
- АБС - это десктоп-приложение с логикой в хранимых процедурах, возникнут трудности с интеграцией интернет-банкинга,
  потребуются доработки на стороне АБС, и тщательный план по интеграции
